# Contact Form ✉️

A custom-designed contact form built with HTML and CSS, featuring a clean, modern interface and working email delivery.

The form allows visitors to enter their name, email address, and message. When submitted, the message is delivered to my Gmail inbox.

## ✨ Features

- 🎨 **Custom UI Design** — A clean interface with a soft color palette and gradient button.
- 📝 **Contact Fields** — Input fields for name, email, and message.
- 📩 **Email Delivery** — Submitted messages are delivered to my Gmail inbox through the configured form service.
- 📱 **Responsive Layout** — Designed to provide a good experience across different screen sizes.
- ⚡ **Simple & Lightweight** — Built with HTML and CSS.

## 🛠️ Built With

- **HTML5** — Form structure and content.
- **CSS3** — Styling, layout, colors, and visual design.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR-REPOSITORY-URL
   ```

2. Open the project folder:

   ```bash
   cd contact-form
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

**Note:** The form's email functionality depends on its configured form service. Opening the HTML file locally may not be sufficient to send messages.
